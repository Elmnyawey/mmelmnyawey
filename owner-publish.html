إضافة مقال جديد

اكتب المقال بالعربي والإنجليزي، وراجع معاينته، ثم انسخ بيانات النشر وافتح GitHub Actions. النشر الفعلي يحتاج تسجيل الدخول إلى GitHub بحساب عنده صلاحية على المستودع.

مهم: الصفحة دي مش موجودة في قائمة الموقع ولا في Sitemap، وGoogle مطلوب منه ما يفهرسها. لكن رابطها مش كلمة سر. الحماية الحقيقية إن النشر محصور في صلاحيات GitHub. متشاركش رابط الإدارة، ومتدخلش أي Tokens أو كلمات مرور في الصفحة.

1. إعداد المقال

حروف إنجليزية صغيرة وأرقام وشرطة - فقط. لا تغيّره بعد النشر.

2. النسخة العربية

كل سطر غير فارغ يظهر كنقطة في المقال، بحد أقصى 50 سطرًا.

3. English version

Each non-empty line becomes one numbered item.

معاينة سريعة

4. انشر من حساب GitHub

انسخ البيانات بالزر ثم افتح رابط GitHub Actions. اختار Run workflow والصق البيانات في حقل article_json، ثم شغّل العملية. Cloudflare هينشر المقال تلقائيًا بعد تنفيذ العملية بنجاح.

معلومات مهمة
  1. أول مرة قد تحتاج تفعيل GitHub Actions من تبويب Actions، والسماح للـ Actions بالكتابة في المستودع من الإعدادات.
  2. لو عنوان الـSlug موجود بالفعل، النشر هيتوقف؛ غيّر الاسم.
  3. محتوى المقالات المنشورة عام ويظهر في صفحات المقالات بالعربي والإنجليزي.
  4. صفحة الإدارة دي نفسها مش محتاجة كلمة مرور لأنها لا تحفظ ولا تنشر شيئًا بدون GitHub.
